# Launch notes (post Phase 0)

Use after a green `app-v*` release with **all four** platform assets (Windows, macOS, Linux, Android).

## Checklist before posting

- [ ] Latest release includes `download-everything-macos-universal.zip`
- [ ] In-app update icon appears when running an older build against the new tag
- [ ] README install table lists Releases + package manager templates under `packaging/`
- [ ] No marketing that implies a live paste-to-cloud web downloader

## Suggested channels

1. **Show HN** — focus on local-first + Instagram Stories/cookies + desktop+Android same brand
2. **r/opensource**, **r/flutterdev** — link Releases, not a hosted API
3. **Flutter / yt-dlp Discords** — ask for APK/desktop testers

## Sample blurb

> Download Everything is a free, ad-free yt-dlp GUI for Windows, macOS, Linux, and Android. Paste a link, pick quality, save locally — including Instagram Stories with cookies. No accounts, no cloud download API. Open source: https://github.com/drmikecrypto/download-everything
